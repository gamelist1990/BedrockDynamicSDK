BedrockDynamicSDK

Minecraft Bedrock（Windows x64）向けの Mod 開発 SDK です。C++20 の DLL Mod と、ScriptClient で動く TypeScript Mod を作れます。どちらもクライアント向けです。

インストール・ビルド

Releases からゲームのビルドに対応する配布物を選びます。TS Mod を使う場合は Windows x64 の DLL Mod ローダーで ScriptClient.dll を読み込みます。

ソースからは、xwin 対応の環境を用意し、リポジトリのルートでビルドします。出力先は dist/<version>/ です。

./build-linux.sh

--stage-a を付けると SDK・DynamicClient・CheckSig のみをビルドします。公開 SDK は sdk/、同梱 Mod とサンプルは exsample/ にあります。

最初の Mod

C++

次の CMakeLists.txt と hello.cpp を同じフォルダーに置きます。Windows で MSVC x64・CMake・Python 3 を用意します。

cmake -S . -B build -A x64 -DSDK_DIR=C:/path/to/BedrockDynamicSDK
cmake --build build --config Release --target Hello

hello.cpp。ゲーム側で Creator Content Log を有効にし、DLL のロード後にローダーから startMod を呼びます。アンロード前に stopMod を呼びます（戻り値はいずれも成功時 true）。

TypeScript

Minecraft.Windows.exe の隣に mods/Hello/ を作ります（書き込めない場合は DLL の隣）。次の 2 ファイルを置き、ScriptClient を起動してワールドに入ります。

manifest.json

{
  "name": "Hello",
  "version": "1.0.0",
  "apiVersion": "1.0.0",
  "gameVersions": ["1.26.65.1"],
  "entry": "index.ts"
}

gameVersions は使うゲームのビルドに合わせます。index.ts はそのまま配置でき、実行時の @bedrock/sdk は ScriptClient が提供します。
