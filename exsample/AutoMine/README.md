# AutoMine

Baritone（Java版）風の自動採掘クライアントMod。対象ブロックを指定すると、付近を探索して歩いて近づき、最適なツールに持ち替えて掘り続ける。

## 使い方

| コマンド | 動作 |
| --- | --- |
| `/mine <ブロックID>` | 採掘開始（例: `/mine iron_ore`、`/mine stone`、`/mine oak_log`） |
| `/mine status` | 現在の状態をチャットに表示 |
| `/mine stop` | 停止（合成入力は全て解放される） |

ブロックIDはローカル名（`minecraft:` なし）で完全一致。見つからない場合は約2秒間隔で再探索するので、歩き回れば新しいエリアでも掘り始める。

※ コマンドはパケット経路で捕捉する方式のため、補完候補には出ない（SDKのネイティブコマンドは整数引数のみ対応）。

## 仕組み

- **探索**: プレイヤー中心に半径（既定24、設定で変更可）を走査し、最も近い対象ブロックへ向かう。掘れない場所（到達不能・タイムアウト）はブラックリストして次を探す。
- **移動**: ゲーム本来の入力経路だけで歩く。キーはネイティブキーボード経路、視点と攻撃は実イベントと同じ形で `MouseDevice::feed` へ流す（SDKのマウスAPI・回転コンポーネント書込み・OS合成入力はこのクライアントでは視点/破壊に効かないことを実測で確認済み）。サーバーからは通常のプレイヤー操作に見える。段差は自動ジャンプ、正面が塞がれていれば掘り抜け、2ブロック以上の落下崖は進まない。位置はプレイヤーのAABB（足元）基準で読む。
- **採掘**: 対象を向いて攻撃ボタンを押し続け、ブロックが消えたらドロップ回収に1歩進む。
- **AutoTool**: ブロック種別（ツルハシ/斧/シャベル/クワ/ハサミ）と必要素材ランクから、ホットバー内の最適ツールを自動選択する。ダイヤ鉱石に木のツルハシ、のような無駄掘りはしない。
- **AutoCraft（計画）**: 使えるツールがホットバーに無い場合、見えている持ち物から「板材→作業台→棒→木のツルハシ→石のツルハシ」の最短手順を計算してチャットで伝え、待機する。ツールがホットバーに現れたら自動で再開する。パケット（ItemStackRequest）による実際の自動クラフトは次期ステップ。

## 設定

`Documents/PEXData/AutoMine/config.json`

```json
{ "enabled": true, "radius": 24 }
```

## 注意

- 採掘中は視点とキー入力をModが占有する。チャットやGUIを開くと（ゲームプレイ非アクティブで）自動的に一時停止する。
- 視点操作にはマウスデバイスの捕捉が必要。参加後に一度でも実マウスを動かせば有効になる（通常のプレイでは自然に満たされる）。
- 縦方向は「届く範囲＋掘り抜け」が中心で、深い縦穴を掘り進む階段掘りは未対応。
