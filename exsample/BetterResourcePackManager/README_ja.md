# BetterResourcePackManager Windows v21（実機未検証）

Minecraft Windows 1.26.60.5 専用。v20のブロック描画・カスタムUV更新を維持し、モデル参照の更新と、設定を開いたままの即時適用を追加しました。

グローバルリソースの有効化・無効化・並べ替えでゲーム側の選択変更処理が通知された時に、元から存在する自動適用経路を利用します。対象はワールド内のグローバルリソース画面だけです。選択変更処理の間だけ自動適用フラグを有効にし、同じコントローラーからの適用に通常終了時と同じ保存フラグを渡します。フラグは元へ戻します。選択ベクトルと非同期コールバックはゲーム側が所有し、Modは偽のキャプチャを作成したり、画面コントローラーの生ポインターを保持して後で呼び出したりしません。通常のネイティブ読込画面が一時的に出る場合があります。

追加更新の「HUD／ポーズ画面へ戻るまで待つ」条件を削除しました。設定画面のままでも、アトラスとローダーの完了、同じ更新要求・ローダー・アトラスを確認したフレームの終了を待ち、次のメインフレームで反映します。秒数による待機はありません。読み込みそのものやフレーム境界の安全確認は省略しません。

モデルについては、ゲーム自身が利用しているClientInstanceの描画バインディング無効化処理を1回呼び出します。既存のエンティティ描画キャッシュを更新対象にし、次の通常描画で参照を再取得させる候補です。形状定義、ActorRenderer全体、AppPlatform停止・復帰、クライアント資源全体の再初期化は行いません。モデル表示が回復するかは実機未確認です。

使われなくなった全体リロード用カウンターの内部保持と通常ログ出力も整理しました。既存SDK Statusの旧フィールドは互換性のため0を返します。

Minecraftを完全終了してDLLを交換してください。先頭は `adapter v21 immediate bindings candidate` です。ログは `Documents/PEXData/BetterResourcePackManager/` です。

設定を閉じずにパックを切り替え、`immediate_selection` → `apply_event` → 読込完了 → `custom_uv_result` → `model_bindings_invalidate` と進むか確認してください。通常ログの `immediate_selections` は即時適用対象の通知数、`model_bindings_refreshed` はモデル参照更新処理の完了回数です。件数は実際の表示成功を保証しません。

実機確認が必要なのは、即時反映、三人称／インベントリの自分のモデル、他のプレイヤー、カスタムブロックの新旧配置、連続切替、設定終了時に不要な再読込が起きないこと、外部サーバーの接続維持です。Windowsビルドと自動テストの成功は、これらの確認とは別です。
