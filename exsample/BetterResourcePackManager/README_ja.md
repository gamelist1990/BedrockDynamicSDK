# BetterResourcePackManager Windows v21

Minecraft Windows x64 **1.26.60.5** 専用。v21のHook・カスタムブロック表示・モデル参照更新・設定中の即時適用は、ユーザーの動作確認に基づき検証済みとして記録しています。

この配布はv21の読み込み完了待ちを補修した版です。設定を開いたまま有効化・無効化・並べ替えを行うと、ゲーム本来の選択変更と保存処理を利用し、リソースの読み込み完了後に反映します。固定秒数の待機はありません。今回変更した待機・再試行処理の実機確認は別途必要です。

アトラスの更新、ローダーの完了、同じ要求・ローダー・アトラスでのフレーム終了を確認します。描画タスクの待機中に追加の読み込みが始まった場合は、適用要求を捨てず、読み込み完了後に再試行します。連続切替時は前の適用が完了するまで次のネイティブ適用コールバックを待機させます。選択データとコールバックの所有権はゲーム側に保ちます。

描画更新は、ブロック描画定義の更新、共有マテリアルを保持したカスタムブロックUV補正、エンティティの描画参照無効化、カメラ更新です。アプリ全体の停止・復帰通知、全形状定義のリロード、クライアント資源全体の再初期化は削除済みです。

Minecraftを完全終了してDLLを交換してください。ログは `Documents/PEXData/BetterResourcePackManager/` に作成します。先頭は `adapter v21 load-complete` です。`readiness_retries` は、追加読み込みの検出によって再試行した回数です。件数だけでは実際の表示成功を保証しません。

SDK側の構成と次バージョンへの更新手順は [API保守ガイド](https://github.com/gamelist1990/BedrockDynamicSDK/blob/main/docs/resource-packs.md) を参照してください。
